{{- if eq .Values.authentication.provider "embeddedDex" }}

Authentication uses the embedded Dex provider at:

  {{ include "osmo.authentication.issuer" . }}

Embedded Dex uses volatile memory storage and is intended for development and
evaluation only. Dex restarts invalidate active sessions and signing keys.
Production deployments should use `authentication.provider: externalOidc`.

Configured local users:
{{- range $identityID, $identity := .Values.authentication.bootstrap.identities }}
{{- if and $identity.enabled (eq $identity.kind "user") (dig "enabled" false ($identity.dex | default dict)) }}

  Username: {{ $identity.username }}
  Email: {{ $identity.dex.email }}
  Password (prints sensitive material; use only in a private terminal):
    kubectl --namespace {{ $.Release.Namespace }} get secret {{ include "osmo.bootstrap.dexPasswordSecretName" $identityID }} --output jsonpath='{.data.password}' | base64 --decode; printf '\n'
{{- end }}
{{- end }}

Generated credential Secrets are retained across Helm upgrades and uninstall.
To rotate one credential, delete only its named Secret and run the next Helm or
GitOps reconciliation. Do not place decoded values in shell history or logs.

{{- if hasPrefix "http://" .Values.externalUrl }}
WARNING: HTTP is for trusted development networks only. Passwords, authorization
codes, bearer tokens, and session cookies can be intercepted. Use HTTPS for
production.
{{- end }}
{{- else }}

Authentication uses the external OIDC issuer:

  {{ .Values.authentication.externalOidc.issuer }}

For an HTTPS JWKS URI, Envoy validates the certificate with its system CA bundle
and requires the exact DNS SAN configured in authentication.externalOidc.jwksHost.
{{- end }}
